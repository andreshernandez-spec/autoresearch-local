# Lessons: how to work in this project

What earlier sessions learned about the way of working here: commands that
went wrong, steps that wasted a run, habits that helped. Not about the problem
itself, which is `KNOWLEDGE.md`. `arl lesson add --scope project` appends an
entry, usually at an introspection. `arl reload` prints this file, and every
agent reads it before it works. A lesson never overrides `PROGRAM.md` or the
protocol.
